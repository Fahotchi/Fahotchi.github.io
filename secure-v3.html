Mizan Import — إدخال رسائل البنك بالخلفية

كل مستخدم يربط الاختصار بحسابه مرة واحدة، وبعدها لا يفتح Safari نهائيًا

من إعدادات ميزان → Mizan Inbox → أنشئ مفتاحك وانسخه
Shortcuts → Mizan Import → Get Text from Shortcut Input
أضف URL: https://snhmckjyhiizzsqgraec.supabase.co/functions/v1/sms-ingest
أضف Get Contents of URL → Method: POST → Request Body: JSON
Header: X-Mizan-Token = مفتاحك، وJSON: message = متغير Text
احذف URL Encode وOpen URLs القديمة. Automation تبقى Run Immediately → Mizan Import
بهذا الشراء والكاش باك يدخلان كرسالتين مستقلتين حتى لو وصلا وراء بعض، وميزان ما يفتح Safari ولا يحتاج تسجيل دخول لكل رسالة
