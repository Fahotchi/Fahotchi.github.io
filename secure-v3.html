Mizan Import — إدخال رسائل البنك

كل مستخدم يضبط الاختصار على جواله مرة واحدة.

Shortcuts → + → سمِّ الاختصار Mizan Import.
أضف Get Text from Shortcut Input.
أضف URL Encode.
أضف Text واكتب رابط ميزان الرئيسي ثم #sms= وبعدها متغير URL Encoded Text.
أضف Open URLs.
Automation → Message → اختر مرسلي البنوك → Run Immediately → Run Shortcut: Mizan Import.
إذا الحساب غير مسجل دخول، ميزان يطلب تسجيل الدخول أولًا ثم يستورد الرسالة بعد التحقق.

Mizan Collect — إرسال القطات

ميزان ينشئ لكل شخص رابط دفع آمن Token قابل للإلغاء والانتهاء.

أنشئ Shortcut باسم Mizan Collect.
Get Dictionary from Shortcut Input.
Get Value للمفتاح items.
Repeat with Each Item.
داخل Repeat: Get Value for phone → Set Variable Phone.
Get Value for message → Set Variable Message.
Send Message: النص = Message والمستلم = Phone.
عطّل Show When Run إذا ظهر لك.
لا تكتب كلمة Phone أو Message يدويًا داخل Send Message؛ اختر المتغير نفسه.
