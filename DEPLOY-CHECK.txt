Mizan Secure v4.4

New update system:
- version.json is the single source of truth for latest release
- app checks for updates automatically after startup
- app re-checks every 30 minutes and when returning to the app
- settings update button performs a real server check
- update banner appears only when a newer version exists
- update clears only Mizan application caches, not Supabase account data
- PWA start_url is versioned
- Service Worker cache is v4.4

Data safety:
- user state remains in Supabase
- updating does not delete transactions, settings, people, or splits
